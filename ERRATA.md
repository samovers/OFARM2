# Errata register

The **only** file in this package that accumulates law feedback during implementation. The law freeze holds: findings are recorded here, never patched into reference copies or canonical files. One consolidated amendment after the pilot processes this register.

Rules:
1. One entry per finding; never edit reference copies or extracted contracts in place.
2. An extraction bug (package text contradicts canonical law) is resolved against the canonical repository and recorded here.
3. A law bug (canonical law contradicts implementation reality) is recorded here with evidence and **worked around within law** until the post-pilot amendment.

| E-007 | 2026-06-20 | LAW_FRICTION | AS_OF spine reconstruction (M2 G6) selects the in-force vintage of each spine family by its effective timestamp (`generatedAt`/`evaluatedAt`/`issuedAt`), but the `AgronomicCodeBindingProfile` carries a lifecycle `profileState` (`ACTIVE`/`DRAFT`/`DEPRECATED`/`SUPERSEDED`) with **no temporal lifecycle data** (when a vintage became — or ceased to be — ACTIVE). G6 can therefore pick, as the latest-issued vintage `<= as_of`, a profile record whose *current* state is non-ACTIVE, and cannot tell whether that vintage was ACTIVE *at* `as_of`. Two reasonable behaviours diverge — (a) refuse (a non-ACTIVE in-force vintage means the context is not reconstructible into a usable profile) vs (b) skip non-ACTIVE vintages and select the latest ACTIVE one — and the choice is a profile-lifecycle/supersession decision beyond G6's timestamp-based selection scope. Found by the G6 self-review (uncaught-`RuntimeError` finding). | `kernel/context.py` `_spine` (`profileState != "ACTIVE"` check, now path-split); profile-state enum in `contracts/core/OFARM_AgronomicCodeBindingProfile_schema_v0_1.json`; append-only records mean `profileState` is fixed-at-insert and never reflects state-at-`as_of`. | G6 adopts behaviour (a) for the AS_OF path: a non-ACTIVE selected profile vintage raises `ContextNotReconstructible` → governed `MATERIALIZATION_INVALID` via `resolve_for_use` (refuse over pretend, rule 7), **never an uncaught 500**. The NOW path keeps the loud `RuntimeError` (a non-ACTIVE *current* profile is a bootstrap/configuration error). Not reachable in the pilot (single ACTIVE profile; nothing writes non-ACTIVE). The richer behaviour (b) and a temporal profile-lifecycle model are **DEFERRED** to a post-pilot decision. |
